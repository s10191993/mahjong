# 🀄 線上麻將（台灣 16 張）＋ 🃏 德州撲克

同一個伺服器提供兩種遊戲，在大廳選擇要開哪一種；加入別人的房間時會自動切成該房的遊戲。

| | 麻將 | 德州撲克 |
|---|---|---|
| 人數 | 固定 4 人 | 2～**8 人** |
| 設定 | 底／台、圈數、骰規 | **小盲／大盲**、起始籌碼 |
| 引擎 | `mahjong.py` + `game.py` | `poker.py` + `poker_game.py` |

德州撲克完整支援：盲注、翻牌前／翻牌／轉牌／河牌四輪下注、蓋牌／過牌／跟注／
加注（滑桿與 ½池・池快捷）／全下、**邊池**、攤牌比牌型、莊家鈕輪轉。


跟朋友連線對戰的網頁麻將。伺服器用 Python（aiohttp），前端純網頁，朋友開瀏覽器輸入房號就能加入。

## 檔案結構

| 檔案 | 說明 |
|------|------|
| `mahjong.py` | 純規則引擎：牌、胡牌判斷、吃碰槓、聽牌。可獨立 `python mahjong.py` 跑自我測試 |
| `game.py` | 單局狀態機：發牌、補花、摸打、吃碰槓胡優先權、台數。`python game.py` 跑 300 局隨機對局測試 |
| `server.py` | 連線伺服器（網頁 + WebSocket 同一程序）。伺服器權威，防作弊 |
| `static/` | 前端牌桌（index.html / style.css / client.js） |
| `test_client.py` | 4 條連線的端到端測試 |
| `fill_bots.py` | 放機器人進既有房間補位（一個人也能測） |

## 如何啟動

```bash
python mahjong/server.py
```

然後瀏覽器開 **http://localhost:8080**

## 怎麼跟朋友一起玩

- **同一台電腦測試**：開伺服器後，找出你的區網 IP（`ipconfig`），朋友連 `http://你的IP:8080`
- **同一個 Wi-Fi（區網）**：同上，用內網 IP 即可
- **常駐網頁版（推薦）**：部署到免費雲端主機，得到一個**固定網址、隨時可玩**，
  你的電腦關機也沒關係。做法見 **[部署指南.md](部署指南.md)**。

- **臨時開台（朋友在遠端、不想部署時）**：**雙擊 `線上開台.bat`**。
  它會同時開「麻將伺服器」和「對外通道 cloudflared」兩個視窗；
  幾秒後在通道視窗會出現一行 `https://xxxx.trycloudflare.com`，
  把那行網址貼給朋友，他們用瀏覽器打開就能加入。
  - 註：cloudflared 已用 `winget install Cloudflare.cloudflared` 裝好，
    路徑 `C:\Program Files (x86)\cloudflared\cloudflared.exe`。
  - 註：每次開台網址會不一樣（臨時通道）。想要固定網址需申請 Cloudflare 帳號做具名通道。

一人開新房間當房主 → 把**網址 + 4 碼房號**給朋友 → 四人到齊 → 房主按「開始遊戲」。
（朋友連的是同一個網址；房號是用來進到同一桌。）

## 玩法

- 輪到你時：**點手牌**打出；若能自摸/暗槓/加槓會跳出按鈕
- 別人打牌後：若能吃碰槓胡會跳出按鈕，或按「過」
- 一局結束顯示台數與分數，房主按「下一局」繼續（莊家胡或流局則連莊）
- **剛摸到的那張牌會獨立擺在最右邊**（金框標示），不會排進手牌裡
- 牌桌左上角：**↻ 重開**（房主限定，重新洗牌發牌、分數保留）、**✕ 離開**（退出牌局回大廳）
- 等待室有「離開房間」；房主離開會自動把房主轉給還在的人，房間沒人就自動回收

## 手機全螢幕（避免網址列擋畫面）

iPhone Safari 沒有網頁全螢幕 API，**真正全螢幕要「加到主畫面」**：

- **iPhone**：Safari 開網址 → 下方「分享」→ **加入主畫面** → 從主畫面圖示開啟，
  就沒有網址列了（本專案已設定 `apple-mobile-web-app-capable` 與 manifest）。
- **Android Chrome**：選單 → **安裝應用程式／加到主畫面**；或直接按牌桌右上角的 **⛶** 按鈕。

即使不安裝，畫面也已針對網址列做調整：高度改用 `100dvh`（實際可見高度）、
支援瀏海安全區 `viewport-fit=cover`，大廳／等待室在橫向會自動壓縮成一頁。

## 牌面圖檔

牌面用真實牌照片，放在 `static/tiles/`，檔名＝牌代碼（`m1.png` 一萬、`p8.png` 八筒、
`dz.png` 中、`f1.png` 春…見該資料夾的 `命名對照.txt`）。

- 支援 `.png / .jpg / .jpeg / .webp`，**有圖用圖、缺圖自動退回內建自繪牌面**，可混用。
- 牌背預設用 CSS 斜紋；若要用圖，放 `tiles/back.png` 並把 `tiles.js` 的
  `USE_BACK_IMAGE` 改成 `true`。
- **想換整副牌**：把整副牌大圖（9 欄 × 5 列排列）丟給切圖腳本即可：

```bash
python mahjong/slice_tiles.py "大圖路徑.png"
```

  它會自動偵測格線、切成 42 張並輸出到 `static/tiles/`，
  同時產生 `slice_check.png` 對照表供檢查。

- **牌面總覽頁**（一次看全部 42 張，方便核對）：http://localhost:8080/static/tiles.html

## 台數（可在 `game.py` 的 `TAI` 字典自行調整）

- **基本**：自摸、門清、門清自摸、連N拉N、正花、花槓
- **莊家台（1台）**：只要莊家有關就算——莊家胡牌、**莊家放槍**、或別人自摸（莊家也要付）。
  唯一不算的情況是「閒家放槍給閒家」。
- **牌型**：平胡、對對胡、混一色、清一色、字一色、大/小三元、大/小四喜、
  三/四/五暗刻、全求人、獨聽、圈風、門風、三元牌刻
- **情境**：槓上開花、搶槓、海底摸月、河底撈魚、天胡、地胡、人胡
- **特殊牌型**：
  - **哩咕哩咕（全對）**：17 張全部湊對，因奇數補一組刻子（7 對 + 1 刻）＝ 8 台
  - **大不搭**：十六不搭且同花色間距「剛好都是 3」（如 1-4-7）＝ 16 台
  - **小不搭**：十六不搭但間距 ≥3、非全部剛好 3（如 1-4-8）＝ 8 台

## 底 / 台 與 骰規（房主在等待室設定）

- **底 / 每台**：預設底 100、每台 20。結算＝**底 + 台數 × 每台**（每一份）。
- **骰規（可開關）**：每局開始擲 3 顆骰──
  - **全紅**（三顆都是紅點 1/4）：+1 台
  - **順子**（三顆連號）：+1 台
  - **豹子**（三顆同點）：該局總額**翻倍**
  骰子結果會顯示在牌桌與結算畫面。
